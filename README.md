## Projetos

### 📊 Análise de NPS — Canais Digitais PJ
> **Ferramentas:** Python · Pandas · Matplotlib · Streamlit · SQL

Análise exploratória de NPS (Net Promoter Score) para canais digitais de clientes pessoa jurídica, simulando o contexto de uma instituição financeira.

**O que o projeto responde:**
- Qual canal digital apresenta melhor e pior NPS?
- Como o NPS varia por safra (período de abertura de conta)?
- Quais segmentos de clientes concentram as maiores insatisfações?
- Qual a evolução do NPS ao longo do tempo?

**Arquivos:**
| Arquivo | Descrição |
|---|---|
| [`case_nps_karina.ipynb`](./case_nps_karina.ipynb) | Análise completa — exploração, limpeza e visualizações |
| [`case_nps_karina.py`](./case_nps_karina.py) | Versão script da análise |
| [`dashboard_nps.py`](./dashboard_nps.py) | Dashboard interativo (Streamlit) |
| [`Case NPS - Karina_Queiroz.pptx`](./Case%20NPS%20-%20Karina_Queiroz.pptx) | Apresentação executiva dos resultados |

**Como executar o dashboard localmente:**
```bash
pip install streamlit pandas matplotlib
streamlit run dashboard_nps.py
```
